# Slow Computer Performance

## Common Symptoms
- Laptop/desktop is generally sluggish, apps take a long time to open.
- High fan noise and the machine feels hot.
- Freezing or "Not Responding" windows.

## Common Causes
- Too many startup programs launching automatically.
- Low disk space (especially on the main drive).
- Background updates or antivirus scans consuming CPU.
- Too many browser tabs/extensions consuming RAM.
- Malware or a runaway background process.
- Outdated OS or hardware nearing its usable lifespan.

## Step-by-Step Troubleshooting
1. Restart the computer fully (not just sleep/lock) - this clears memory leaks that build up over days.
2. Open Task Manager (Windows: Ctrl+Shift+Esc) or Activity Monitor (macOS) and sort by CPU/Memory to identify which process is consuming resources.
3. Disable unnecessary startup programs (Task Manager > Startup tab, or System Settings > General > Login Items on macOS).
4. Check free disk space; free up space if the main drive is over 90% full (empty Recycle Bin/Trash, clear Downloads folder, use Disk Cleanup).
5. Run a full antivirus/malware scan using the company-approved security tool.
6. Close unused browser tabs and disable/remove unused browser extensions.
7. Check for pending OS and driver updates and install them (updates often include performance fixes).
8. If the machine is more than 4-5 years old and still slow after all the above, hardware upgrade or replacement may be the real fix.

## When to Escalate
Escalate if a malware scan finds an active infection, or if the slowness started right after a specific software installation/update (may need IT to roll it back).
